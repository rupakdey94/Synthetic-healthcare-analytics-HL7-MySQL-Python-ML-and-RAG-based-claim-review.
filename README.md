# Synthetic-healthcare-analytics-HL7-MySQL-Python-ML-and-RAG-based-claim-review.
Synthetic healthcare analytics project using HL7 messages, MySQL, Python and machine learning to predict claim denial risk. Includes NLP, FAISS-based policy retrieval and a Qwen LLM to draft source-cited claim-review checklists. Built with Google Colab using synthetic claims and policy documents.
